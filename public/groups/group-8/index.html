Sequence 04

Fibonacci Numbers

About This Sequence

The Fibonacci sequence is a famous mathematical pattern where each term is the sum of the two preceding ones. Starting with 0 and 1, it models natural growth and relates closely to the Golden Ratio (φ). In automata theory, it frequently appears in the analysis of self-referential grammars and recursive state machines.

F(0) = 0, F(1) = 1, F(n) = F(n−1) + F(n−2)

Sequence 05

Lucas Numbers

About This Sequence

The Lucas sequence shares the same recursive addition rule as the Fibonacci sequence but begins with different seeds: 2 and 1. Despite this difference, it exhibits the same asymptotic growth and converges to the Golden Ratio. In computer science, Lucas numbers are vital for prime testing algorithms and constructing pseudoprimes.

L(0) = 2, L(1) = 1, L(n) = L(n−1) + L(n−2)

Tribonacci Numbers

About This Sequence

The Tribonacci sequence extends the standard Fibonacci rule by summing the three preceding terms instead of two. Beginning with the seeds 0, 0, and 1, it grows at a faster rate and converges to the Tribonacci constant (τ ≈ 1.839). It finds practical application in computational biology for modeling three-way branching processes.

T(0)=0, T(1)=0, T(2)=1, T(n) = T(n−1) + T(n−2) + T(n−3)

Algorithm 01

Division Algorithm

About This Algorithm

The Division Algorithm states that for any two positive integers m and n (where m > n), there exist unique integers q (quotient) and r (remainder) such that m = n·q + r, where 0 ≤ r < n. This fundamental theorem underpins modular arithmetic and is a building block for the Euclidean Algorithm.

m = n · q + r, where 0 ≤ r < n

Algorithm 02

Euclidean Algorithm

About This Algorithm

The Euclidean Algorithm is an efficient method for computing the greatest common divisor (GCD) of two positive integers. It repeatedly applies the Division Algorithm until the remainder is zero. The last non-zero remainder is the GCD. From the GCD, the least common multiple (LCM) can be derived as LCM(a,b) = (a × b) / GCD(a,b).

gcd(m, n) = gcd(n, m mod n) until r = 0

Algorithm 03

Collatz Sequence

About This Sequence

The Collatz conjecture (also known as the 3n+1 problem) generates a sequence from any positive integer: if the current term is even, divide by 2; if odd, multiply by 3 and add 1. The conjecture states that this sequence always eventually reaches 1, regardless of the starting value. It remains one of the most famous unsolved problems in mathematics.

If even: n/2 | If odd: 3n + 1
